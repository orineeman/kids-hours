# בקרת אינטרנט לילדים — WhatsApp Web ואתרים נוספים

מערכת שרצה על מחשב הילדים (Windows). כל אתר שמוגדר ברשימה **חסום כברירת מחדל**;
ההורה נכנס ללוח בקרה בדפדפן (מכל מחשב, כולל מרחוק) ומעניק גישה זמנית ל-X דקות —
לאחר מכן האתר נחסם אוטומטית מחדש. המערכת גם רושמת דוח של כל הדומיינים שהמחשב
ניגש אליהם.

הארכיטקטורה המלאה, האופציות שנשקלו, ונקודות התורפה שטופלו — מתועדות בתוכנית
המקורית שאיתה נבנה הפרויקט. הסבר קצר על איך זה עובד:

- **DNS resolver מקומי** (בתוך `src/dnsServer.js`) — כל שאילתת DNS מהמחשב עוברת
  דרכו. הוא בודק אם הדומיין ברשימת "האתרים המנוהלים" וללא גרנט פעיל — במקרה כזה
  מחזיר NXDOMAIN. אחרת מעביר לשרתי DNS ציבוריים ומחזיר את התשובה האמיתית, וגם
  רושם אותה בלוג לצורך הדוח.
- **שרת Web + לוח בקרה** (`src/webServer.js`, `public/`) — כניסה מאובטחת להורה,
  רשימת אתרים עם כפתור "פתח ל-X דקות", ודוח גלישה.
- **Windows Firewall דינמי** (`src/firewall.js`) — בנוסף לחסימת ה-DNS, כל IP
  אמיתי שנצפה עבור אתר חסום נחסם גם ברמת ה-Firewall. זה מה שסוגר גם session
  שכבר פתוח, וגם מונע גישה ע"י הקלדת כתובת IP ישירה (עוקפת DNS).

## התקנה — שלב אחר שלב (על מחשב הילדים, Windows)

### 0. דרישות מוקדמות
- Node.js (גרסה 18 ומעלה) מותקן על מחשב הילדים.
- חשבון הילד במחשב מוגדר כ-**Standard User** (לא Administrator) — קריטי, אחרת
  כל ההקשחה חסרת ערך כי אפשר לעקוף אותה בקלות. את הפרויקט וההתקנה יש לבצע
  מחשבון Administrator נפרד.

### 1. התקנת החבילות
```powershell
cd path\to\whatsapp-kids-hours
npm install
```

### 2. בדיקה ראשונית (לפני הפיכה לשירות)
```powershell
node src\index.js
```
בדפדפן: `http://localhost:8080` → יוביל ישר למסך הכניסה (login.html) עם חשבון
הורה שנזרע אוטומטית בהרצה הראשונה: שם משתמש `עדידוש`, סיסמה `1234`.

> **אזהרת אבטחה**: `1234` היא סיסמת ברירת מחדל חלשה מאוד וקל לנחש אותה תוך
> שניות במסך הכניסה עצמו — זה בדיוק מה שהמערכת אמורה למנוע מהילד. מומלץ
> מאוד להחליף אותה מיד אחרי ההתקנה. אין כרגע מסך "שינוי סיסמה" בלוח הבקרה;
> הדרך להחליף היא לערוך ידנית את הטבלה `parent_users` ב-`data/app.db`
> (למשל עם `sqlite3`), או למחוק את השורה הקיימת ואז לגלוש שוב ל-`/` — זה
> יציג את מסך ההגדרה הרגיל (setup.html) ליצירת חשבון חדש.

> שימו לב: כברירת מחדל השרת מנסה להאזין ל-DNS על פורט 53, שדורש הרשאות
> Administrator ב-Windows. הריצו את הבדיקה הזו מ-PowerShell **כ-Administrator**.

### 3. התקנה כשירות Windows (רץ תמיד, גם בלי login, עם auto-restart)
מ-PowerShell **כ-Administrator**:
```powershell
node install\service-install.js
```
זה יוצר שירות בשם `KidsNetControl` שרץ תחת SYSTEM, עולה עם המחשב, ומוגדר
להתאושש אוטומטית מכל קריסה. להסרה: `node install\service-uninstall.js`.

### 4. הקשחה נגד עקיפה
מ-PowerShell **כ-Administrator**:
```powershell
powershell -ExecutionPolicy Bypass -File install\harden.ps1
```
הסקריפט מבצע בבת אחת: הגדרת DNS מקומי, כיבוי Chrome Secure DNS, חסימת
התקנת תוספי Chrome, חסימת DNS/DoH חיצוני ב-Firewall, ונעילת הרשאות על
תיקיית ההתקנה. אפשר להריץ שוב בבטחה בכל עת (idempotent).

### 5. גישה מרחוק ללוח הבקרה — Cloudflare Tunnel
כדי להיכנס ללוח הבקרה **מכל מחשב**, לא רק מרשת הבית. הדומיין `musagim-bamaharal.org`
כבר מנוהל דרך Cloudflare (פרויקט קיים) — משתמשים בו כאן רק כדי להוסיף
תת-דומיין חדש (`kids.musagim-bamaharal.org`), בלי לגעת ברשומות הקיימות של
הפרויקט האחר:

1. התקינו את `cloudflared` על מחשב הילדים (הורדה מאתר Cloudflare).
2. התחברו וצרו טאנל חדש:
   ```powershell
   cloudflared tunnel login
   cloudflared tunnel create kids-control
   cloudflared tunnel route dns kids-control kids.musagim-bamaharal.org
   ```
   הפקודה האחרונה רק **מוסיפה** רשומת CNAME חדשה לתת-הדומיין הזה — היא לא
   נוגעת בשום רשומה קיימת אחרת בדומיין.
3. הגדירו את הטאנל להצביע ל-`http://localhost:8080` (קובץ `config.yml` של
   cloudflared), והתקינו אותו כשירות Windows: `cloudflared service install`.
4. מעכשיו הכתובת `https://kids.musagim-bamaharal.org` נגישה מכל מקום, ללא
   צורך בפתיחת פורטים בראוטר, ובלי סיכון לפרויקט הקיים על אותו דומיין.

(ההתקנה המדויקת של cloudflared תלויה בגרסה העדכנית — כדאי לעקוב אחרי המדריך
הרשמי של Cloudflare Tunnel בזמן ההתקנה בפועל.)

## בדיקות מומלצות אחרי ההתקנה
- אתחול מלא למחשב → לוודא שהשירות עולה לבד ושהחסימה פעילה כברירת מחדל.
- מחשבון הילד: לנסות לשנות DNS / להתקין תוסף כרום / להקליד IP ישיר של וואטסאפ
  → לוודא שכל ניסיון נחסם.
- מהלוח: להעניק 2 דקות לוואטסאפ, לוודא שנפתח בפועל, ולוודא שנחסם מחדש לבד
  אחרי הזמן.
- לוודא אילו דומיינים וואטסאפ ווב טוען בפועל (יכול להשתנות עם הזמן) ולעדכן את
  הרשימה ב`sites.domains` בהתאם דרך "הוספת אתר" בלוח הבקרה.

## מגבלות ידועות
מכשירים אחרים (טלפון, טאבלט, מחשב אחר) לא מכוסים ע"י המערכת הזו; עקיפה ברמת
אתחול (Safe Mode / USB חי) דורשת הגנת BIOS/UEFI נפרדת שלא כלולה כאן.
